# Mecha Fighter: game credits

Every asset the game uses, with its source and licence. Paths are relative to `godot/`; a path ending in `/` covers everything below it. The Credits screen (`ui/screens/credits_screen.gd`) reads this table at runtime, so add a row whenever you add an asset.

## Inspiration

Mecha Fighter is an independent remix inspired by Konami's 1982 arcade game *Time Pilot*. It uses no Konami assets and is not affiliated with Konami.
