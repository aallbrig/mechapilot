# Threat model: infrastructure and AWS evaluation

Covers `infra/`, `scripts/infra`, the deploy role's trust policy and the aws-security-evaluation skill (`scripts/aws-eval/`). The attacker is a change that weakens deployed infrastructure while every scan stays green, or that leaks account identifiers into this public repository.

| ID | Attack class | Description | Found | Status | Mitigation | Proof |
| --- | --- | --- | --- | --- | --- | --- |
| IN-01 | Inline scanner suppression | A `trivy:ignore` comment above a resource silenced a HIGH finding. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Inline suppression markers are rejected in every Terraform file. | `test:test_infra_no_suppressions_rejects_trivy_inline_ignore` |
| IN-02 | Auto-loaded scanner config | A repo-root `trivy.yaml` with `skip-files` was picked up automatically. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Only the committed, schema-checked config is used; stray configs are rejected. | `test:test_infra_no_suppressions_rejects_stray_trivy_config` |
| IN-03 | Scanner environment variables | `TRIVY_SKIP_FILES`, `TRIVY_MISCONFIG_SCANNERS` or `TRIVY_IGNORE_POLICY` switched the scan off. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Every `TRIVY_*` variable is cleared before the scan. | `test:test_infra_scan_ignores_trivy_skip_files` |
| IN-04 | Suppression outside the scanned tree | A module outside `infra/` carried an ignore marker the check never read. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Markers are checked in every tracked Terraform file in the repository. | `test:test_infra_no_suppressions_scans_terraform_outside_infra` |
| IN-05 | Remote module skips the scan | A module with a remote source was downloaded under `.terraform` and never scanned. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Module sources are judged from what OpenTofu resolved; non-local sources fail. | `test:test_infra_modules_rejects_git_source` |
| IN-06 | Unquoted block label | `module x { ... }` escaped a regex that expected a quoted label. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Bare labels are parsed and unusual forms fail closed. | `test:test_infra_no_suppressions_rejects_unquoted_remote_module` |
| IN-07 | Override files | A `*_override.tf` is merged by OpenTofu, but the scanner judges the secure base block. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Override files are refused by validate, scan and the suppression check. | `test:test_infra_validate_and_scan_refuse_override_files` |
| IN-08 | Symlinked configuration | A symlinked `.tf` file is loaded by OpenTofu but skipped by the scanner. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Symlinks under `infra/` are refused. | `test:test_infra_validate_and_scan_refuse_symlinks` |
| IN-09 | Committed variable files | A force-added `*.auto.tfvars` flips a secure default the scanner judged. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Tracked tfvars files are rejected. | `test:test_infra_no_suppressions_rejects_committed_tfvars` |
| IN-10 | Local variable files | Untracked tfvars change what a human deploys after a clean scan. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | The scan judges local tfvars too. | `test:test_infra_scan_judges_local_tfvars` |
| IN-11 | CLI and variable overrides | `TF_VAR_*`, `TF_CLI_ARGS*` or a CLI config file change what OpenTofu evaluates. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | They are cleared and the CLI config is forced empty. | `test:test_infra_clears_variable_and_cli_overrides` |
| IN-12 | Trust policy OR of claims | A ref claim alone, without the protected environment, could assume the deploy role. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | One exact subject (StringEquals, no wildcards) that requires both `refs/heads/main` and the production environment (#31). | `test:test_deploy_role_trusts_main_production_only` |
| IN-13 | Claim injection through names | A crafted environment name with `:ref:` segments tries to satisfy the subject. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | The subject is compared exactly, with the fixed environment segment last, so no spliced name can equal it. | `test:test_deploy_trust_rejects_colon_tricks_in_environment_names` |
| IN-14 | Identifier smuggled as a hash | A short `zh:<digits>` string in a lock file was blanked before the identifier scan. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Only exact provider-hash shapes are blanked. | `test:test_infra_no_identifiers_rejects_short_hash_lookalikes_in_lock_files` |
| IN-15 | Identifier in exact hash shape | A fake lock-file entry with the exact hash shape can still carry digits. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | open | Planned: verify lock-file hashes against the pinned provider releases. | #54 |
| IN-16 | Abbreviated CLI options | The AWS CLI accepts unambiguous prefixes, so `--endpoint=` slipped past a full-name denylist. | [#45](https://github.com/aallbrig/mechapilot/pull/45) | mitigated | Only the options the scripts pass are allowed. | `test:test_aws_eval_aws_ro_refuses_writes` |
| IN-17 | Negated condition hides an open trust | A `StringNotEquals` on `sub` was counted as pinning it, so an open OIDC trust scored clean. | [#45](https://github.com/aallbrig/mechapilot/pull/45) | mitigated | Only positive operators pin `sub` and `aud`. | `test:test_aws_eval_flags_oidc_trust_pinned_only_by_negation` |
| IN-18 | Identifiers with separators | Account IDs written with dashes or spaces passed redaction. | [#45](https://github.com/aallbrig/mechapilot/pull/45) | mitigated | Redaction accepts any separator. | `test:test_aws_eval_redact_accounts_with_any_separator` |
| IN-19 | Hosts that look like files | Multi-label hosts under TLDs that are also file extensions were kept as paths. | [#45](https://github.com/aallbrig/mechapilot/pull/45) | mitigated | The file exemption applies only to two-label names. | `test:test_aws_eval_redact_hosts_with_file_like_tlds_in_paths` |
