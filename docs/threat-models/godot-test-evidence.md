# Threat model: Godot test evidence

Covers the GdUnit4 runner (`scripts/godot-test`), the GDScript static bans and the `godot.xml` evidence the runner writes. The Godot skeleton PR (#49) mitigates each entry and names its regression test. The attacker is GDScript test or project code that wants a failing test reported as passed.

| ID | Attack class | Description | Found | Status | Mitigation | Proof |
| --- | --- | --- | --- | --- | --- | --- |
| GT-01 | In-process result forgery | Test code shares a process with GdUnit4's counters and report writer, so it can rewrite its own suite's verdict. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | residual | Accepted: one process per suite, static bans on reflection, process and file APIs, and review of every test and the helpers it calls. | #37 |
| GT-02 | Fail-open report on crash | A crashed or early-quitting suite left a `godot.xml` that claimed passes. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | A failed or crashed suite records every case as failed, plus its exit status. | `test:test_godot_test_fails_every_case_of_a_hung_suite` |
| GT-03 | Reflection through bound methods | `.map(obj.get)` and similar reach runner internals by string without call syntax. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Reflective names are banned as whole words, so calls and method references are both rejected; property accessors are the only exception. | `test:test_safe_api_rejects_method_reference_reflection` |
| GT-04 | Path escape from user:// | Concatenated paths and `globalize_path` let a test overwrite the harness or the Godot binary. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Every FileAccess, save and load path must be one complete literal with no `..`; path-resolving and environment APIs are banned; on Linux CI each Godot process runs under bubblewrap with a read-only filesystem; tree-guard fails every case if the repo, node_modules or the Godot install changed. | `test:test_godot_test_harness_rewrite_never_passes_unnoticed` |
| GT-05 | Filesystem through instances | `DirAccess.open(...).copy(...)` overwrites a report through an instance, not a banned static call. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | `DirAccess` is banned outside addons; FileAccess takes only one literal `user://` path (or reads one literal `res://` path). | `test:test_safe_api_rejects_dir_access_instance_copy` |
| GT-06 | Tampering in non-test helpers | Test-only bans do not follow calls into helpers outside `tests/`. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Scene-tree escape bans (`.root`, `get_parent`, `owner`, `get_viewport`, group lookups, climbing or absolute node paths) apply to all project code. | `test:test_safe_api_rejects_helper_walking_from_root` |
| GT-07 | Detached process from a test | `OS.create_process` starts a process that rewrites results after they are written. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Process, argv and environment APIs are banned in project code; each suite runs in its own process group, killed when the suite ends. | `test:test_safe_api_rejects_process_spawn_anywhere` |
| GT-08 | Cross-runner overwrite | GDScript tests can overwrite `shell.xml`, which is written earlier. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | `scripts/godot-test` copies `shell.xml` aside before the Godot run and fails every case if it changed. | `test:test_godot_test_detects_shell_xml_overwrite` |
| GT-09 | Watchdog holds stderr open | An orphaned watchdog `sleep` keeps a pipe open, so piped runs hang for the full limit. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | The watchdog sleep has no inherited stdio and is killed with the watchdog; the command group is killed when it ends. | `test:test_run_with_timeout_returns_promptly_with_piped_stderr` |
| GT-10 | Broken scene passes compile check | A scene with a missing `ext_resource` prints a parse error but exits 0. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | The compile check fails on any `ERROR:`, `SCRIPT ERROR:` or `Parse Error` line. | `test:test_compile_check_rejects_scene_with_missing_script` |
| GT-11 | Cache poisoning | The CI cache was saved after project code ran, and a cache hit never re-hashed the binaries. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | CI saves the cache right after install, before project code runs; `install-godot` re-hashes the unpacked binary and templates against pinned sums on every run. | `test:test_install_godot_rejects_a_tampered_install` |
| GT-12 | Unguarded toolchain pins | `.godot-version` and its checksum file changed with one review. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | `.godot-version`, `.godot-sha512sums` and `godot/addons.sha256` are verification paths. | `test:test_guard_flags_godot_pins` |
| GT-13 | Frame and exit hooks | `process_frame`, `physics_frame` or `tree_exiting` handlers zero the counters before the exit code is computed, or rewrite `results.xml` after it is written. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Every route to a runner handle (root, parent, reflection, internals) is banned; under bubblewrap a rewrite reaches only the suite's own report, and a mismatched report fails the suite. | `test:test_safe_api_rejects_frame_hook_on_root` |
| GT-14 | Internals named in strings | String literals name runner members (`_console_reporter`, `_summary`, `report_base_path`) for reflection or subscripts. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | Literals containing "gdunit", an underscore name with "report", or any `_`-prefixed member declared in addons/ are rejected, as are `__` identifiers. | `test:test_safe_api_rejects_literal_naming_vendored_internal` |
| GT-15 | Hung suite never killed on Linux | dash refuses `set -m` without a terminal, so no process group existed and the timeout's group kill silently missed a spinning Godot. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | `setsid` on Linux, `kill -s SIG -- -PGID`, the PID signalled directly, and TERM escalating to KILL after 5 s. | `test:test_run_with_timeout_kills_command_ignoring_term` |
| GT-16 | Orphaned command on interrupt | A signal to the wrapper missed the command, which runs in its own group or session, and left it running. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | INT, TERM and HUP are trapped and forwarded to the command group, with KILL after 5 s. | `test:test_run_with_timeout_forwards_signals_to_the_command` |
| GT-17 | Code at import time | `@tool` scripts run inside the editor and during `--import`, before any test guard is in place. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | mitigated | `@tool` is banned in project code; under bubblewrap the import also runs sandboxed. | `test:test_safe_api_rejects_tool_scripts` |
