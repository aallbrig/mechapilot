# Threat model: release and deploy

Covers `.github/workflows/release.yml` and `deploy.yml`, `scripts/release/`, `scripts/checks/production-dispatch-only` and `scripts/checks/workflow-permissions` (#31). The attacker is anything other than the owner's press of Deploy that changes Production, or a deploy that ships bytes the release workflow did not build.

| ID | Attack class | Description | Found | Status | Mitigation | Proof |
| --- | --- | --- | --- | --- | --- | --- |
| RD-01 | Replaced release assets | Any Contents-write token re-uploaded every asset of a bot-published release with a consistent manifest and checksums, and the deploy shipped it. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | Pre-flight requires an immutable release or every asset uploaded by the release workflow, and downloads each asset by its id. | `test:test_deploy_verifies_release_checksums` |
| RD-02 | Helper clobbers a caller variable | A helper reused the caller's loop variable, so pre-flight checked one site's rollback target twice and refused mixed-version deploys forever. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | Helper variables are prefixed per helper, and pre-flight starts from an empty releases directory. | `test:test_deploy_preflight_checks_each_site_rollback_target` |
| RD-03 | Dotfile workflow | A workflow named like `.evil.yml` with a production job on push was skipped by the workflow checks. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | Every top-level workflow file is checked, dotfiles included, and symlinks are refused. | `test:test_production_dispatch_only_rejects_automatic_triggers` |
| RD-04 | Lookalike environment name | An environment such as `production ` (trailing space) was not counted as production. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | Names are lowercased and reduced to letters and digits, and anything containing prod counts as production. | `test:test_production_dispatch_only_rejects_automatic_triggers` |
| RD-05 | Hand-published release as latest | A release published by a person with a higher version made every latest deploy refuse. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | latest, previous and exact_version resolve only among releases the release workflow published, from every page. | `test:test_deploy_resolves_version_input` |
| RD-06 | Failed upload hidden by the old file | A failed wasm upload left the old object, whose headers still passed the post-deploy check. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | The post-deploy check compares the served bytes with the manifest sha256. | `test:test_deploy_postcheck_compares_served_sha256` |
| RD-07 | Glob characters in sync excludes | A pre-gzipped path containing a glob character would make `aws s3 sync --exclude` match other files. | [#72](https://github.com/aallbrig/mechapilot/pull/72) | mitigated | Packaging refuses file names with glob characters. | `test:test_release_manifest_matches_schema` |
