# Threat model: merge gate and acceptance evidence

Covers `scripts/merge-gate`, `scripts/verify-acceptance`, `scripts/ci-verdict`, `scripts/review-verdicts`, `scripts/checks/verification-guard`, the test runners' result files and the `ci` workflow. The attacker is a PR author (human or agent) who wants an unproven change merged, or wants one review where two are required.

| ID | Attack class | Description | Found | Status | Mitigation | Proof |
| --- | --- | --- | --- | --- | --- | --- |
| MG-01 | Regex injection in a criterion | A `test:` name used as a pattern (`.*`) matches any passing test. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Test names must match exactly, as fixed strings. | `test:test_rejects_pattern_test_names` |
| MG-02 | Path traversal in a criterion | `check:../<path>` runs any executable in the PR, outside the guarded `scripts/checks/`. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Check names may not contain `/` or `..`. | `test:test_rejects_check_path_traversal` |
| MG-03 | Results written by test code | A test file's top-level code writes its own JUnit file into the results directory. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Only the runners' own result files count, and `task test` fails on any other file there. | `test:test_test_results_clean_rejects_planted_files` |
| MG-04 | Results file of another runner | Test code writes `godot.xml` with `tests/shell/` classnames, where no Godot runner exists. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Each result file may only vouch for its own runner's directory. | `test:test_rejects_shell_tests_vouched_by_godot_results` |
| MG-05 | Definition the runner never runs | `test_x ()` with a space, or a definition in a fixture, counts as defined but never runs. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | One shared discovery helper (`scripts/lib-tests`) decides what is defined. | `test:test_rejects_definition_runner_would_not_discover` |
| MG-06 | Classname not bound to its source | A result names a test whose definition lives in a different file. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | The classname file must itself define the test. | `test:test_rejects_classname_file_that_does_not_define_test` |
| MG-07 | Trivially true criterion | `task:default` or another no-op target proves nothing but passes. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Setup, maintenance and side-effecting targets are rejected. | `test:test_rejects_trivial_task_targets` |
| MG-08 | Criteria the parser skips | Checklist items written with `*` or numbers were neither counted nor failed. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Every list item in the section is a criterion. | `test:test_counts_star_and_numbered_items` |
| MG-09 | Gate runs PR code with the operator's credentials | `task:` and `check:` criteria ran the PR's Taskfile and scripts on the merge host with a live GitHub login. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | The gate only judges evidence CI recorded; it executes nothing from the PR. | `test:test_evidence_mode_judges_recorded_results_without_running` |
| MG-10 | Verdicts from any account | Any GitHub account could post `review-verdict: pass` comments. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Only the owner account's comments count. | `test:test_verdicts_ignore_non_owner_comments` |
| MG-11 | Verdict not bound to the head | A pass on an earlier commit still counted after a push. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Each verdict names the full head SHA. | `test:test_verdicts_pass_requires_head_sha` |
| MG-12 | Quoted verdict lines | An example verdict quoted in a status comment cleared a real block. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Only a comment's last non-empty line counts. | `test:test_verdicts_only_last_line_counts` |
| MG-13 | Guessable synthetic tag | A malformed verdict's synthetic reviewer tag could be cleared by a well-formed pass with the same tag. | [#57](https://github.com/aallbrig/mechapilot/pull/57) | mitigated | The synthetic tag uses a character the strict format cannot produce. | `test:test_verdicts_malformed_block_cannot_be_cleared_by_guessing_its_tag` |
| MG-14 | Stale ci success | A cancelled newer `ci` run was ignored, so an older success stood in for it. | [#57](https://github.com/aallbrig/mechapilot/pull/57) | mitigated | The newest `ci` run must succeed; a cancel is ignored only before a later success. | `test:test_ci_verdict_newest_run_must_succeed` |
| MG-15 | Truncated check-run list | Only the first page of check runs was read, so a failure could be pushed onto page 2. | [#57](https://github.com/aallbrig/mechapilot/pull/57) | mitigated | All pages are read and the count must equal `total_count`. | `test:test_ci_verdict_fails_closed_on_missing_pages` |
| MG-16 | Re-run hides a failed attempt | The default `filter=latest` hid a failed attempt behind its re-run. | [#57](https://github.com/aallbrig/mechapilot/pull/57) | mitigated | All attempts are read and any failure blocks. | `test:test_ci_verdict_fails_when_any_run_failed` |
| MG-17 | Rename into a guarded path | A rename showed only its old, unguarded path to the guard. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | The guard diffs with `--no-renames`. | `test:test_guard_flags_rename_into_checks` |
| MG-18 | Nested tool config | A nested `.shellcheckrc`, `.yamllint` or similar file silently weakens a linter. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Tool configs are guarded at any depth. | `test:test_guard_flags_nested_shellcheckrc` |
| MG-19 | Test weakened in place | Editing an existing test (`! cmd` to `true`) needed only one review. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Modified or deleted tests are verification changes. | `test:test_guard_flags_modified_test` |
| MG-20 | Inline suppression | A `shellcheck disable` or similar directive in an unguarded file. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | Added suppression directives are verification changes anywhere. | `test:test_guard_flags_inline_suppression` |
| MG-21 | Unguarded measurement config | `lighthouserc.json`, `.htmlvalidate.json` or `lychee.toml` changed with one review. | [#47](https://github.com/aallbrig/mechapilot/pull/47) | mitigated | Site measurement configs and their ignore files are guarded. | `test:test_guard_flags_site_measurement_configs` |
| MG-22 | Unguarded validator directive | An `html-validate-disable` comment suppresses a validator rule. | [#47](https://github.com/aallbrig/mechapilot/pull/47) | mitigated | The guard flags html-validate directives. | `test:test_guard_flags_html_validate_directives` |
| MG-23 | Unguarded config location | A mise config at a location the guard did not list (for example `.config/mise.toml`) sets environment that disables a scan. | [#48](https://github.com/aallbrig/mechapilot/pull/48) | mitigated | Every mise config location is guarded. | `test:test_guard_flags_every_mise_config_location` |
| MG-24 | Residual relabelled to dodge a block | Editing a threat model to mark a finding residual would stop it blocking, with one review. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | `docs/threat-models/` is a verification path. | `test:test_guard_flags_threat_model_changes` |
| MG-25 | Threat model drifts from its proofs | An entry claims a mitigation whose test or check no longer exists. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | `task lint` checks every mitigated entry's proof. | `check:threat-models` |
| MG-26 | Self-posted verdicts | The owner account, which the Agent Loop also holds, can post passes under any tag, edit a block into a pass, or post throwaway verdicts to inflate the round count past round 3. | [#62](https://github.com/aallbrig/mechapilot/pull/62) | residual | Accepted until verdicts come from an identity the loop does not hold; reviewers are subagents told to break the change. | #35 |
| MG-27 | Merge outside the gate | The owner token can merge a ci-green PR through the REST API without running the gate. | [#62](https://github.com/aallbrig/mechapilot/pull/62) | residual | Accepted; the Agent Loop's runtime pin keeps a merged change from running unsandboxed until a human pins it. | #35 |
| MG-28 | Criteria edited after CI | An issue's acceptance criteria can change after CI and review, so the gate judges criteria CI never ran. | [#16](https://github.com/aallbrig/mechapilot/pull/16) | mitigated | CI records a sha256 of each issue's acceptance section as its verifier parsed it; main's verifier refuses at merge if the section it reads now hashes differently. | `test:test_merge_gate_refuses_issue_body_edited_after_ci` |
| MG-29 | Evidence tampered before upload | Test code, or a process it left behind, runs in the job that uploads the evidence. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | open | Planned: hash results when the runners finish, or record evidence in a separate job. | #37 |
| MG-30 | Acceptance record reachable from tests | Child processes of a `task:test` criterion can learn the acceptance record path and append to it. | [#57](https://github.com/aallbrig/mechapilot/pull/57) | open | Planned: hide the path from children or record from a separate job. | #58 |
| MG-31 | Test that never asserts | A test that sources a helper calling `exit 0`, or has no assertions, passes. | [#49](https://github.com/aallbrig/mechapilot/pull/49) | open | Planned: a sentinel after each test, and review of every helper a test calls. | #41 |
| MG-32 | PR relabels its own hole | A PR lowers a row it is judged by (for example `mitigated` to `residual`), so the policy tells reviewers not to block. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | Only main's copy counts; the lint rejects removals and downgrades against `origin/main` without a `threat-model-downgrade:` trailer. | `test:test_threat_models_rejects_status_downgrade` |
| MG-33 | PR accepts the hole it introduces | A PR adds a `residual` row for a hole it creates. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | A row may not be born `residual` without a `threat-model-downgrade:` trailer, which reviewers judge. | `test:test_threat_models_rejects_new_residual_row` |
| MG-34 | Comparison skipped in CI | Without main's ref the base comparison could silently not run. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | Under CI a missing merge-base fails the lint. | `test:test_threat_models_requires_a_base_in_ci` |
| MG-35 | Hidden second table | A pipe-less or blockquoted table renders on GitHub as entries the check never parsed. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | No pipe may appear outside the one table, and README.md holds no table. | `test:test_threat_models_rejects_hidden_second_table` |
| MG-36 | Proof check that never runs | A `check:` proof exists on disk but no task in `task ci` runs it, so its mitigation is unenforced. | [#69](https://github.com/aallbrig/mechapilot/pull/69) | mitigated | A check proof must be called by a task reachable from `ci`. | `test:test_threat_models_rejects_check_not_run_by_ci` |
| MG-37 | Retarget after CI | With no CI re-run on a base change, a PR goes green against a side branch that carries the implementation, then is retargeted to main. | [#71](https://github.com/aallbrig/mechapilot/pull/71) | mitigated | CI records the base ref and SHA it tested; the gate requires the live base, the recorded base and an ancestor of origin/main to all be main. | `test:test_merge_gate_refuses_ci_evidence_from_a_non_main_base` |
| MG-38 | Linked issues swapped after CI | With no CI re-run on a PR-body edit, the `Closes #n` set changes to issues CI never evaluated. | [#71](https://github.com/aallbrig/mechapilot/pull/71) | mitigated | CI records the linked issues it evaluated; the gate refuses unless the set is unchanged. | `test:test_merge_gate_refuses_pr_links_changed_after_ci` |
| MG-39 | Binding entry ambiguity | Several or padded binding lines for one issue let a forged line stand in for the real one. | [#71](https://github.com/aallbrig/mechapilot/pull/71) | mitigated | Exactly one binding line per issue, compared as a string; malformed or unreadable bindings are refused. | `test:test_binding_requires_exactly_one_entry_per_issue` |
